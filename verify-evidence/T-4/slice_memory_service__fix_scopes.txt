  568 |     AND text `render_file` could have written, so hand-authored markdown indexed via
  569 |     `memory import --markdown` is never deleted.

  571 |     Idempotent: a second run moves nothing. A dry run computes the same report and writes
  572 |     nothing, including the file list.
