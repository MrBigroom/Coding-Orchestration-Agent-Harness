107:def authorized_contract_files(task: Task) -> set[str]:
108:    """Contract files this task explicitly authorizes changes to.
109:
110:    Authorization means a *grant*, not a mention: a Definition of Done item, acceptance criterion
111:    or frozen-contracts entry must (a) name the file and (b) grant a change to it — "authorized to
112:    amend docs/frozen-contracts.md to add the ORCH_VERIFY field names". Three things are
113:    deliberately NOT authorization, each with a test:
114:
115:    - a **mere mention**, e.g. "intersect the changed-file set with docs/frozen-contracts.md";
116:    - a **prohibition**, e.g. "Do NOT modify docs/frozen-contracts.md";
117:    - anything in the task **description**, a commit message or a diffstat — only the three stored
118:      authorization fields above are read.
119:
120:    Failing closed is the point: a control that authorizes the edit it was written to detect is
121:    worse than no control, because it reads as a check that passed.
122:    """
123:    texts = [
124:        *(task.definition_of_done or []),
125:        *(task.acceptance_criteria or []),
126:        *(task.frozen_contracts or []),
127:    ]
128:    clauses = _grant_clauses(texts)
129:    if not clauses:
130:        return set()
131:    return {p for p in CONTRACT_FILES if any(_mentioned(c, p) for c in clauses)}
