# Decision log

Running log of architecture decisions. Newest last. Format: date — decision — why.

- **2026-10-19 — Project lives at the repository root** (not a `coding-orchestrator/`
  subfolder). The package/CLI is still `coding-orchestrator` / `orchestrator`. Chosen by
  the user.
- **2026-10-19 — Integer IDs + human short IDs** (`T-12`, `R-34`). Simple joins, and
  artifact paths (`runs/<int>`) can't be traversal vectors.
- **2026-10-19 — Alembic owns the schema.** `0001_baseline` was autogenerated from the
  models, then rewritten to plain SQLAlchemy types so it doesn't depend on SQLModel
  internals. A test checks models and migrations for drift.
- **2026-10-19 — Timezone-aware UTC timestamps.** SQLModel ≥ 0.0.48 maps datetimes to
  `UTCDateTime`, which rejects naive datetimes.
- **2026-10-19 — Deterministic Supervisor; the LLM Supervisor only recommends.** Gate
  decisions (verification, review trigger, accept/requeue/block, merge) live in
  `supervisor_service`. LLM supervisor profiles exist for recommendations only, per spec.
- **2026-10-19 — Fail-closed review parsing.** Ambiguous output, or a VERDICT line that
  disagrees with the JSON verdict, becomes CHANGES_REQUESTED. Missing artifacts downgrade
  APPROVED.
- **2026-10-19 — Bounded review loop.** CHANGES_REQUESTED requeues the Worker on the same
  branch, up to `max_review_rounds` (3), then blocks for a human, so automated retries
  can't burn tokens forever.
- **2026-10-19 — Agent/cron tasks skip the Architect** unless they are high-risk, so
  background jobs don't spend Opus tokens.
- **2026-10-19 — Handoff file inside the worktree** at `.orchestrator/handoff.json`, added
  once to the repo's local `info/exclude`. Many harnesses restrict writes to their cwd,
  and the exclude keeps it out of commits.
- **2026-10-19 — Cross-process cancellation via a `CANCEL` marker file** in the run
  directory, polled by the process runner, so `orchestrator task cancel` works even when
  the run lives in the server process.
- **2026-10-19 — WebSocket tails artifact files** instead of an in-memory bus only, so runs
  started from the CLI stream to the GUI too.
- **2026-10-19 — Recovery commits never stage sensitive files** (`.env`, keys,
  credentials); those stay untracked.
- **2026-10-19 — Anthropic: no `temperature`, use `effort`.** The installed SDK (1.x) no
  longer accepts sampling params, and Claude Opus/Sonnet 5.5 reject them. Refusal fallback
  is on by default with `fallbacks="default"`.
- **2026-10-19 — Qwen provider defaults to the Token Plan endpoint**, by the user's choice,
  despite Alibaba's terms restricting Token Plan to interactive tool use. The warning is
  documented in README, providers.md, `.env.example`, and the provider row's notes.
- **2026-10-19 — Primary supervisor = `qwen3.8-max`, Sonnet alternate**, by the user's
  choice (lower cost).
- **2026-10-19 — Worker profiles on Token Plan IDs**: `qwen3.8-flash`,
  `deepseek-v4.1-flash`, `glm-5.3`, all listed by Model Studio. DeepSeek's own API uses
  `deepseek-flash`.
- **2026-10-19 — Adapter defaults:** Qwen Code binary corrected to `qwen -p`, and OpenCode
  to `opencode run "<msg>"` (the spec's `--prompt-file` flag doesn't exist there). DeepSeek
  Harness and ZCode keep the spec's placeholders, explicitly marked unverified.
- **2026-10-19 — Tailwind v4 with `tailwind.config.js` via `@config`** to keep the spec's
  file layout while using the current major version. Frontend: React 19, Vite 8,
  TypeScript 7.
- **2026-10-19 — APScheduler 3.x** (stable line; 4.x isn't stable). Cron is evaluated in UTC.
- **2026-10-19 — Fallback UI is a single static HTML file** with no build step and no
  dependencies, served when `web/dist` is missing.
- **2026-10-19 — Architect runs through `claude -p` on the user's Claude Pro subscription**
  (new `claude_cli` provider kind, profile `architect-claude-cli`, preferred over
  `architect-opus`). Basis: Anthropic's Help Center allows `claude -p` on subscription
  limits, and its legal page reserves OAuth for native Anthropic apps. So the orchestrator
  launches only the unmodified binary, never handles the token, and never forwards
  `ANTHROPIC_API_KEY`. All tools are disabled (`--tools ""`, MCP denied) to enforce the
  Architect's no-execution rule, and calls are serialised. No schema change was needed
  (`providers.kind` is a free string).
- **2026-10-19 — Claude Code Worker adapter no longer forwards `ANTHROPIC_API_KEY`**, for
  the same reason (subscription auth, no silent API billing).
- **2026-10-19 — Qwen default stays on the Token Plan** (user's decision, reconfirmed after
  learning that the interactive-only rule covers every model on the plan, DeepSeek/GLM
  included, and also covers Qwen Cloud's Token Plan).
